# PDF 页面整理器 · Page Desk

[打开在线工具](https://niu866.github.io/pdf-page-sorter/)

导入一份或多份 PDF，拖动列表页面或点击上移、下移调整顺序。预览按钮会在浏览器 PDF 阅读器中打开原文件的指定页面。
按当前列表顺序导出完整 PDF、指定页范围或单页 PDF ZIP。每个工作区最多 400 页，输入合计最多 120 MB。

所有处理都在浏览器内。需要先解密受密码保护的 PDF。页面复制以页内容为主，签名、书签、表单字段等文档属性应另行核对。

本地开发可运行 python -m http.server 8080。压缩版第三方模块在 vendor 目录，相关许可随附。
